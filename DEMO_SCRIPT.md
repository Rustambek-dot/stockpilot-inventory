# Demo Script — StockPilot (4 минуты)

1. **Landing** (20с) — «Know your stock. Always.»
2. **Dashboard** (40с) — стоимость склада, low-stock блок с красной рамкой, графики in/out.
3. **Products** (90с) — главный экран:
   - Поиск по SKU, фильтр категорий, сортировка кликом по колонке
   - Красные «low» бейджи у дефицитных позиций
   - Добавить товар вживую через inline-форму
   - Export CSV одним кликом (файл скачивается)
4. **Movements** (60с) — журнал: типы (in/out/adjust), причины, атрибуция пользователя. Зарегистрировать приход — движение появляется сверху. «В БД это один транзакционный RPC — журнал и остатки не могут разойтись».
5. **Suppliers + Reports** (40с) — CRUD поставщиков; отчёты: стоимость по категориям, оборачиваемость, dead stock.
6. **Settings** (20с) — локации, роли (admin/manager/warehouse).
7. **Финал** (10с) — тёмная тема, мобильная адаптивность.
