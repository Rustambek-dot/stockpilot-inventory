# StockPilot — Inventory Management System — Product Specification

## Обзор
**StockPilot** — система складского учёта: каталог товаров, движения (приход/списание), несколько локаций, минимальные остатки с уведомлениями, CSV импорт/экспорт, отчёты.

## Целевая аудитория
Розница, e-commerce, дистрибуция, небольшое производство (1–10 складов, 100–50 000 SKU).

## Бизнес-задача
Точные остатки в реальном времени; конец «пересорту» и внезапным out-of-stock; история каждого движения товара.

## Роли
- **Admin** — всё: товары, локации, пользователи, отчёты
- **Manager** — товары, движения, отчёты
- **Warehouse worker** — только регистрация приходов/списаний

## Ключевые user flows
1. **Приход**: выбрать товар → количество → локация → поставщик → остаток растёт, движение в журнале
2. **Списание/продажа**: товар → количество → причина (sale/damage/loss) → остаток падает
3. **Low stock**: остаток ≤ min_stock → товар попадает в блок предупреждений на дашборде
4. **Импорт CSV**: загрузка файла → предпросмотр → валидация построчно → создание товаров
5. **Экспорт CSV**: текущие остатки одним кликом (API-роут генерирует файл)

## Страницы
- `/` — landing
- `/auth/*`
- `/dashboard` — стоимость склада, low-stock alerts, движения за неделю, топ-товары
- `/products` — таблица с поиском/фильтрами/сортировкой, CRUD, min-stock
- `/movements` — журнал движений с фильтрами (тип, товар, локация, дата)
- `/suppliers` — CRUD поставщиков
- `/reports` — стоимость по категориям, обороты, экспорт CSV
- `/settings` — локации, пользователи, роли

## База данных
products (id, org_id, sku UNIQUE, name, category, unit, price, cost, min_stock)
locations (id, org_id, name)
stock (product_id, location_id, qty) — PK (product_id, location_id)
movements (id, org_id, product_id, location_id, type: in|out|adjust, qty, reason, user_id, created_at)
suppliers (id, org_id, name, contact, email)
Остаток = материализованное значение в stock, обновляется транзакционно вместе со вставкой movement (RPC-функция).
